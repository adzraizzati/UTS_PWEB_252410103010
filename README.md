Saya memilih membuat aplikasi Manajemen Data Mahasiswa karena ingin membuat sebuah aplikasi sederhana yang dapat membantu menampilkan dan mengelola informasi mahasiswa agar lebih terstruktur dan mudah dilihat.

Selain itu, aplikasi ini saya buat sebagai penerapan materi Pemrograman Web yang sudah dipelajari, khususnya penggunaan Laravel, konsep MVC, dan Blade Template.

Saya juga ingin memahami bagaimana proses perpindahan data dari halaman Login menuju Dashboard, serta bagaimana data ditampilkan dalam bentuk tabel.
